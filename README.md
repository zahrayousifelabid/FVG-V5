# دليل رؤيتك المالي (FVG) — Financial Vision Guide
### منصة المحاسبة الإدارية والتكاليف والتسعير ودعم القرار المالي في البيئات التضخمية
### Management Accounting, Costing, Pricing & Financial Decision Support Platform

---

## 🌟 نبذة عن المشروع / Project Overview

**دليل رؤيتك المالي (FVG)** هو نظام مالي وإداري متكامل مصمم خصيصاً للمدراء الماليين، رواد الأعمال، وأصحاب المنشآت الصغيرة والمتوسطة، برؤية وتوجيه **الأستاذة زهراء يوسف**. يقدم النظام حلولاً حاسمة للمحاسبة الإدارية، تحليل التكاليف، نقطة التعادل، تسعير المنتجات، والتحوط ضد التضخم وتقلب أسعار الصرف.

يتكون المشروع من:
1. **تطبيق أندرويد أصيل (Native Android App)** مبني بلغة **Kotlin** وبواجهات **Jetpack Compose (Material 3)**.
2. **تطبيق ويب تقدمي (PWA)** متجاوب بنسبة 100% يعمل على كافة المتصفحات والأجهزة مع دعم كامل للشاشات والشاشات اللمسية.
3. **قواعد بيانات وسحابة Firebase**: تشمل **Firestore**، **Authentication**، و **Cloud Functions** للإشعارات والتحقق في الوقت الفعلي.

## 📥 روابط التنزيل والتثبيت على كافة الأجهزة / Download & Installation

### 1. نظام أندرويد (Android Phones & Tablets) 🤖
- **ملف التثبيت المباشر (APK)**:
  - متوفر في مجلد الإخراج: `.build-outputs/app-debug.apk`
  - متوفر في ملفات الموقع للتنزيل المباشر: `website/assets/fvg-app-debug.apk`
  - رابط التنزيل المباشر من الموقع: `https://financialvisionguide.web.app/assets/fvg-app-debug.apk`
- **طريقة التثبيت**:
  1. قم بتنزيل ملف الـ APK على هاتفك أو جهازك اللوحي.
  2. افتح الملف واضغط "تثبيت" (Install) — إذا طُلب منك السماح بالتثبيت من مصادر غير معروفة، اضغط "سماح".
  3. يفتح التطبيق بكامل وظائفه مع دعم وضع عدم الاتصال (Offline) وقاعدة بيانات سحابية متزامنة.

### 2. أجهزة أبل آيفون وآيباد (Apple iOS - iPhone & iPad) 🍎
نظرًا لسياسات نظام Apple iOS التي لا تدعم تنزيل وتثبيت ملفات الـ APK مباشرة، تم تصميم منصة FVG كـ **تطبيق ويب تقدمي فائق الأداء (PWA)** يطابق تماماً التطبيق الأصلي مع دعم كامل لخصائص iOS:
- **رابط المنصة**:
  - `https://financialvisionguide.web.app`
  - أو الرابط البديل: `https://ais-pre-loywiqr6itewlzsr7mziwk-735768634987.europe-west1.run.app`
- **خطوات التثبيت على الآيفون والآيباد**:
  1. افتح الرابط في متصفح **Safari** على جهاز iPhone أو iPad.
  2. اضغط على زر **المشاركة** (Share) الموجود في أسفل الشاشة (أيقونة المربع الذي يخرج منه سهم للأعلى).
  3. مرر للأسفل واضغط على **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
  4. سيظهر تطبيق FVG بأيقونته الرسمية الذهبية واسمه الكامل على شاشتك الرئيسية، ويفتح بملء الشاشة بدون شريط متصفح كأي تطبيق أصلي مثبت من الـ App Store.

### 3. أجهزة اللابتوب والكمبيوتر المكتبي (Windows / macOS / Linux) 💻
- افتح الموقع في متصفح **Google Chrome** أو **Microsoft Edge**.
- ستظهر أيقونة تثبيت صغيرة داخل شريط العنوان (Install FVG).
- اضغط عليها ليتم تثبيت البرنامج كنافذة مستقلة فائقة السرعة على سطح المكتب وقائمة البداية.

│   ├── index.html            # الصفحة الرئيسية مع وسوم PWA و Apple Web App
│   ├── app.js                # المنطق البرمجي الكامل (الحاسبات، الذكاء الاصطناعي، لوحة الإدارة)

│   ├── manifest.webmanifest  # إعدادات تثبيت التطبيق

## 🚀 أوامر البناء والرفع إلى GitHub / Git & Build Commands

### 1. الرفع إلى GitHub لأول مرة:
```bash
# تهيئة مستودع Git محلي
git init

# إضافة جميع الملفات (الملفات المؤقتة مستبعدة تلقائياً عبر .gitignore)
git add .

# إنشاء أول Commit
git commit -m "feat: complete release of Financial Vision Guide (Android, Web PWA & Functions)"

# ربط المستودع برابط GitHub الخاص بك
git remote add origin https://github.com/YOUR_USERNAME/FinancialVisionGuide.git

# رفع التغييرات إلى الفرع الرئيسي
git branch -M main
git push -u origin main
```

### 2. بناء تطبيق أندرويد (APK):
```bash
gradle assembleDebug
# الناتج سيكون في: app/build/outputs/apk/debug/app-debug.apk
```

### 3. تشغيل ونشر سحابة Firebase:
```bash
# نشر قواعد الأمان وتطبيق الويب و Cloud Functions
firebase deploy
```

4. **تصدير تقرير تحليلي شامل بصيغة CSV**:
   - إمكانية تنزيل ملف CSV بضغطة زر يحتوي على كافة مؤشرات الأداء، سجلات الزوار، المستخدمين المسجلين، والمدفوعات للتقارير المالية.
5. **نظام الإشعارات اللحظية**:
   - تنبيه فوري للإدارة عند تسجيل أي مستخدم جديد أو رصد أي نشاط غير معتاد عبر مشغلات Firestore السحابية.
